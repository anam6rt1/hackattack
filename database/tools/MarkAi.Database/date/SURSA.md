# Sursa datelor

`siruta_s1_2026.csv` — Registrul unităților administrativ-teritoriale ale României (SIRUTA), semestrul I 2026,
publicat de **Institutul Național de Statistică** pe data.gov.ro (setul „SIRUTA_s1 2026”, actualizat 2026-08-11):
https://data.gov.ro/dataset/siruta_s1-2026

Licență: Creative Commons Attribution 4.0 (CC BY 4.0) — https://creativecommons.org/licenses/by/4.0/
Fișierul este păstrat neschimbat; comanda `MarkAi.Database seed-localitati` îl citește și scrie în baza de date
județele și localitățile (denumiri cu majuscule doar la început și diacritice cu virgulă: ș, ț).
Câmpuri folosite: SIRUTA, DENLOC, JUD, SIRSUP, TIP, NIV, MED (vezi legenda din setul de date).
