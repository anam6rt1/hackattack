# A2 și A5 — API local

## Domeniu aprobat

Stocarea rămâne locală. Nu se introduce S3, nu se migrează fișiere și nu se trimit documente către un serviciu nou. Compresia se execută în browser; serverul oferă configurația și verifică rezultatul prin upload-urile existente. Acest pas adaugă endpoint-uri, fără interfață nouă în Setări sau în formularul de înregistrare.

## Endpoint-uri

| Metodă și rută | Comportament |
|---|---|
| `GET /fisiere/optimizare/config` | Public; formate, limite, pragul economiei, parametrii imaginilor și rutele upload-ului reluabil. Nu primește fișiere și nu execută conversie. |
| `POST /parcursuri/{id}/fisiere` | Upload multipart existent: câmpul `fisier` conține varianta pregătită în browser. Se păstrează verificările de acces, semnătură, macrocomenzi, dimensiune și arhive. |
| `POST /parcursuri/{id}/incarcari` | Upload reluabil existent pentru varianta pregătită, urmat de PUT-uri și finalizare cu SHA-256. |
| `GET /confidentialitate` | Public; informarea versionată, contactul configurat și politica de retenție. Câmpurile operator/contact necompletate rămân null, fără date juridice inventate. |
| `POST /utilizatori/me/date/export` | Autentificare + JSON `{ "parolaActuala": "..." }`. Descarcă `datele-mele.json`, cu `Cache-Control: no-store`. |
| `GET /utilizatori/me/date/documente/fotografie` | Fotografia propriului cont, dacă există. |
| `GET /utilizatori/me/date/documente/dovada` | Documentul de calificare al propriului cont, inclusiv pentru profesorii neaprobați. |
| `DELETE /utilizatori/me/date` | Autentificare + JSON `{ "parolaActuala": "...", "confirmare": "STERGE" }`. Răspuns 202; închide contul, revocă sesiunile și programează curățarea documentelor personale. |

În browser, rutele sunt sub prefixul `/api`. Cererile de modificare/export trimit cookie-ul și antetul `X-MarkAi: 1`. Nu puneți parola, tokenuri sau coduri în URL ori în jurnale.

## Export și închiderea contului

Exportul include profilul, preferințele, apartenențele, progresul, încercările, recompensele, cererile AI, materialele atribuite titularului, rezervările, evidențele financiare și conversațiile. Include metadatele mesajelor trimise și linkuri autentificate către documentele personale. Parolele/hash-urile, codurile, cheile de apel, tokenurile de upload și cheile fizice de stocare nu se exportă. Fișierele binare se descarcă separat, cât timp sesiunea este activă.

Închiderea șterge datele de identificare/contact, progresul și conversațiile contului, elimină apartenențele și dezactivează autentificarea. Rezervările viitoare sunt anulate; plățile simulate se marchează rambursate. Materialele organizației rămân disponibile cu autorul decuplat. Numele fișierelor și conținutul materialelor educaționale păstrate nu sunt rescrise automat; solicitările referitoare la informații personale din materialele altor persoane se tratează separat de operator.

Referințele operaționale/financiare sunt păstrate cu un identificator pseudonimizat. **Aceste evidențe nu sunt declarate anonime și nu sunt șterse integral de acest endpoint.** Politica financiară și termenele aplicabile trebuie stabilite de operator. Administratorii platformei și administratorii organizațiilor trebuie să transfere responsabilitățile înainte de dezactivare.

Curățarea documentelor personale și a upload-urilor neterminate folosește tabela persistentă `stergere_date_cont` și se reia după restart. Eșecurile de acces la disc se reîncearcă; jobul se finalizează doar după ștergere. Cererile de ștergere din teste folosesc exclusiv baze și documente temporare.

## Retenție și declarația privind minorii

`Confidentialitate__ConversatiiZile=0`, `Confidentialitate__MesajeTrimiseZile=0` și `Confidentialitate__MesajeContactZile=0`: **curățarea automată este dezactivată**, conform deciziei proprietarului. Mecanismul poate fi activat ulterior prin valori pozitive; el șterge conținutul conversațiilor telefonice încheiate, mesajele deja trimise și mesajele de contact rezolvate de mai mult de N zile, fără a atinge apelurile active sau mesajele în așteptare.

Înregistrarea elevului acceptă suplimentar `sub16Ani` (boolean) și `acordParinteDeclarat` (boolean). Pentru `sub16Ani=true`, declarația acordului este obligatorie. Se păstrează momentul declarației și versiunea informării, fără colectarea datei complete a nașterii. `Confidentialitate__SolicitaDeclaratieVarsta=true` cere declarația tuturor clienților; implicit este false pentru compatibilitatea interfeței existente. Activați opțiunea după conectarea formularului la câmpurile noi.

Declarația elevului **nu constituie verificarea părintelui**. Mecanismul de autorizare/verificare, temeiurile prelucrării, identitatea operatorului, contactul, subcontractanții și perioadele de păstrare necesită decizie și validare înainte de pilot. Nu se afirmă conformitate GDPR completă prin simpla existență a acestor endpoint-uri.

Configurație disponibilă: `Confidentialitate__Operator`, `Confidentialitate__Contact`, `Confidentialitate__Gazduire`, cele două perioade și opțiunea declarației. Informarea publică se generează din configurația efectivă.

Referință juridică pentru validarea documentelor: [Regulamentul (UE) 2016/679, în special articolele 8, 13, 17, 20 și 28](https://eur-lex.europa.eu/eli/reg/2016/679/oj).
